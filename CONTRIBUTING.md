# Contributing to IntelliHire-AI

Thank you for your interest in contributing to IntelliHire-AI.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a virtual environment.
4. Install the project dependencies.
5. Create a new branch for your changes.

## Development

Before submitting changes, make sure the application runs correctly and that existing functionality is not broken.

## Pull Requests

When submitting a pull request:

* Clearly describe the changes.
* Explain the reason for the changes.
* Keep changes focused and easy to review.
* Test your changes before submitting.

## Issues

If you find a bug or have a feature suggestion, open an issue and provide enough information to reproduce the problem or understand the proposed improvement.

## Code Quality

Please keep the code readable, maintainable, and consistent with the existing project structure.

Thank you for contributing to IntelliHire-AI!
